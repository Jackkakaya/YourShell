## Research archive

The [`research/`](research/) directory contains command inventories,
compatibility studies, implementation plans, and historical decisions.
Research documents may describe an earlier implementation state; current code
and passing tests are authoritative.

The root `docs.tar.gz` is retained as an untouched historical archive.
